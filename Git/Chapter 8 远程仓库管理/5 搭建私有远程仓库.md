# 搭建私有远程仓库

本文采用 Docker + GitLab 开源镜像搭建 Git 服务器。

## 概述

GitLab 是一个利用 Ruby on Rails 开发的开源应用程序，实现一个自托管的 Git 项目仓库，可通过 Web 界面进行访问公开的或者私人项目。

GitLab 拥有与 GitHub 类似的功能，能够浏览源代码，管理缺陷和注释。可以管理团队对仓库的访问，它非常易于浏览提交过的版本并提供一个文件历史库。它还提供一个代码片段收集功能可以轻松实现代码复用，便于日后有需要的时候进行查找。

- 官网：https://about.gitlab.com/

## 搭建

### 拉取镜像

```bash
docker pull gitlab/gitlab-ce
```

### 运行

```bash
mkdir -p /data/gitlab/
docker run -d \
  --restart=always \
  --name=gitlab-ce \
  -p 443:443 -p 80:80 -p 8022:22 \
  -v /data/gitlab/config:/etc/gitlab \
  -v /data/gitlab/logs:/var/log/gitlab \
  -v /data/gitlab/data:/var/opt/gitlab \
  gitlab/gitlab-ce
```

## 修改配置

### 修改 IP 和端口

```bash
cd /data/gitlab/config
cp gitlab.rb gitlab.rb.bak
vi gitlab.rb
```

将：

```ruby
# external_url 'GENERATED_EXTERNAL_URL'
```

修改为：

```ruby
external_url 'http://127.0.0.1'
```

将：

```ruby
# gitlab_rails['gitlab_ssh_host'] = 'ssh.host_example.com'
```

修改为：

```ruby
gitlab_rails['gitlab_ssh_host'] = '127.0.0.1'
```

将：

```ruby
# gitlab_rails['gitlab_shell_ssh_port'] = 22
```

修改为：

```ruby
gitlab_rails['gitlab_shell_ssh_port'] = 8022
```

> 注意：这里表示 GitLab 的 SSH 端口。

### 修改超级管理员 root 的密码

切换到 GitLab 下的 bin 目录：

```bash
cd /opt/gitlab/bin
```

执行如下指令进入 console：

```bash
sudo gitlab-rails console
```

输入如下指令查看所有用户：

```ruby
u = User.all
```

执行如下指令查找和切换到 root 用户：

```ruby
u = User.where(id: 1).first
```

输入如下指令设置 root 用户的密码：

```ruby
u.password = '123456'
```

输入如下指令确认密码：

```ruby
u.password_confirmation = '123456'
```

执行如下指令保存设置：

```ruby
u.save!
```

此时，使用 GitLab 的 `ip:端口` 进行访问，输入 `root/123456` 即可使用超级管理员 root 登录账号。
