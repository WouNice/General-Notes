# 目录操作命令

## mkdir

mkdir（make directory）命令用于创建新的空目录，命令的语法格式如下：

```shell
mkdir [选项] 目录名
```

例如，在当前目录中创建名为 test 的子目录。

```shell
mkdir test
```

例如，在根目录中创建名为 public 的子目录。

```shell
mkdir /public
```

mkdir 命令也可以同时创建多个目录。

例如，在当前目录中同时创建 a、b、c 共 3 个子目录。

```shell
mkdir a b c
```

mkdir 命令的常用选项是“-p”（parent）。通过该选项可以创建嵌套的多级目录结构。

例如，在/root 目录下创建子目录 media，并在 media 目录中再建立子目录 cdrom。

```shell
mkdir -p /root/media/cdrom
```

执行上面的命令后，系统将首先创建/root/media 目录，然后在它下面再创建 cdrom 目录。

## rmdir

rmdir（remove directory）命令的作用与 mkdir 正好相反，使用 rmdir 命令可以删除指定的目录，而且同样可以使用“-p”选项删除多级目录。

例如，一次性删除目录/root/media 及其子目录/root/media/cdrom。

```text
rmdir -p /root/media/cdrom
```

注意，rmdir 命令所删除的必须是空目录（目录中没有任何文件和子目录）。

## pwd

pwd 查看当前工作目录路径

语法格式：pwd [参数]

常用参数：

-   -L：显示逻辑路径

查看当前工作目录路径：

```shell
[root@localhost ~]# pwd
/home/localhost
```

## cd

cd 命令的功能是从当前目录切换到指定目录。

其中目录的路径可分为绝对路径和相对路径。若目录名称省略，则切换至使用者的用户目录(也就是刚登录时所在的目录)。

语法格式：cd [参数] [目录名]

常用参数：

| 参数 | 用法                                                         |
| ---- | ------------------------------------------------------------ |
| `-P` | 如果切换的目标目录是一个符号链接，则直接切换到符号链接指向的目标目录 |
| `-L` | 如果切换的目标目录是一个符号链接，则直接切换到符号链接名所在的目录 |
| `--` | 仅使用”-“选项时，当前目录将被切换到环境变量”OLDPWD”对应值的目录 |
| `~`  | 切换至当前用户目录                                           |
| `..` | 切换至当前目录位置的上一级目录                               |
| `.`  | 表示目前所在的目录                                           |

例如，将当前工作目录切换到 dir 目录，并使用 pwd 命令查看当前目录：

```shell
[root@localhost ~]# cd dir
[root@localhost dir]# pwd
/root/dir
```

使用“cd ../..”命令返回上两级目录：

```shell
[root@localhost dir_2]# pwd
/root/dir/dir_1/dir_2
[root@localhost dir_2]# cd ../..
[root@localhost dir]# pwd
/root/dir
```

使用“cd”命令返回当前用户目录。“cd -- ” 命令返回上一次所在目录：

```shell
[root@localhost dir_2]# pwd
/root/dir/dir_1/dir_2

[root@localhost dir_2]# cd
[root@localhost ~]# pwd
/root

[root@localhost ~]# cd -
/root/dir/dir_1/dir_2
[root@localhost dir_2]# pwd
/root/dir/dir_1/dir_2
```
