# Vim 文本编辑器

Vim 是功能强大的终端文本编辑器，特点是**模式切换**和**键盘操作**。本教程帮你半小时内掌握核心操作。

## 启动与退出

```bash
vim filename       # 打开/创建文件
vim -R filename    # 只读方式打开
```

**退出（务必先记牢）**：
- 按 `Esc` 确保在**正常模式**
- 输入 `:q` 回车 – 退出（未修改时）
- 输入 `:q!` 回车 – 强制退出（丢弃修改）
- 输入 `:wq` 回车 – 保存并退出
- 输入 `:x` 回车 – 也是保存并退出（比 `:wq` 更聪明）

> 💡 新手常困在无法退出：按一次 `Esc`，然后输入 `:q!` 就会强制退出。

## 三种基本模式

| 模式         | 名称         | 进入方式              | 作用                             |
| ------------ | ------------ | --------------------- | -------------------------------- |
| **正常模式** | Normal       | 按 `Esc`              | 移动光标、删除、复制、粘贴、命令 |
| **插入模式** | Insert       | 按 `i` / `a` / `o` 等 | 像普通编辑器一样输入文字         |
| **命令模式** | Command-line | 按 `:`                | 执行保存、退出、搜索、替换       |

> 初次打开 Vim 时处于**正常模式**。按 `i` 进入插入模式，按 `Esc` 返回正常模式。

## 光标移动（正常模式下）

| 按键           | 作用                            | 等效方向键 |
| -------------- | ------------------------------- | ---------- |
| `h`            | 左移一格                        | ←          |
| `j`            | 下移一行                        | ↓          |
| `k`            | 上移一行                        | ↑          |
| `l`            | 右移一格                        | →          |
| `w`            | 跳到下一个单词开头              |            |
| `b`            | 跳到上一个单词开头              |            |
| `0`            | 跳到行首                        |            |
| `^`            | 跳到行首第一个非空字符          |            |
| `$`            | 跳到行尾                        |            |
| `gg`           | 跳到文件首行                    |            |
| `G`            | 跳到文件最后一行                |            |
| `:行号` + 回车 | 跳到指定行（如 `:25` 到第25行） |            |

## 基本编辑操作（正常模式下）

### 进入插入模式的各种方式

| 命令 | 效果                 |
| ---- | -------------------- |
| `i`  | 在光标**前**开始插入 |
| `a`  | 在光标**后**开始插入 |
| `o`  | 下方另起一行插入     |
| `O`  | 上方另起一行插入     |
| `I`  | 跳到行首开始插入     |
| `A`  | 跳到行尾开始插入     |

### 删除（剪切）

| 命令  | 效果                         |
| ----- | ---------------------------- |
| `x`   | 删除光标处的一个字符         |
| `X`   | 删除光标前的一个字符         |
| `dd`  | 删除整行（同时剪切到剪贴板） |
| `3dd` | 删除3行（数字可换）          |
| `dw`  | 删除从光标到单词末尾         |
| `d$`  | 删除从光标到行尾             |
| `d0`  | 删除从光标到行首             |

### 复制与粘贴

| 命令  | 效果         |
| ----- | ------------ |
| `yy`  | 复制当前行   |
| `3yy` | 复制3行      |
| `yw`  | 复制一个单词 |
| `p`   | 在光标后粘贴 |
| `P`   | 在光标前粘贴 |

### 撤销与重做

| 命令       | 效果             |
| ---------- | ---------------- |
| `u`        | 撤销上一步操作   |
| `Ctrl + r` | 重做（撤销撤销） |

## 查找与替换

### 查找（正常模式下）
- `/关键词` 回车 → 向下查找
- `?关键词` 回车 → 向上查找
- `n` → 下一个匹配
- `N` → 上一个匹配

### 替换（命令模式，即按 `:` 后输入）
```
:%s/旧词/新词/g        # 全局替换
:%s/旧词/新词/gc       # 逐个确认
:3,10s/旧/新/g         # 仅第3~10行替换
```

## 常用快捷键组合

| 操作                     | 按键                |
| ------------------------ | ------------------- |
| 保存（无需退出）         | `:w` 回车           |
| 另存为                   | `:w 新文件名`       |
| 查看当前文件信息         | `Ctrl + g`          |
| 显示行号                 | `:set number`       |
| 关闭行号                 | `:set nonumber`     |
| 语法高亮开启             | `:syntax on`        |
| 选中一块文本（可视模式） | `v`（然后移动光标） |
| 选中整行（可视模式）     | `V`                 |
| 复制选中文本             | 按 `y`              |
| 删除选中文本             | 按 `d`              |

## 一个完整的编辑流程示例

```bash
# 1. 在终端中创建文件
vim hello.txt

# 2. 按 i 进入插入模式
# 输入：Hello Vim!
# 输入：This is line two.

# 3. 按 Esc 回到正常模式

# 4. 移动光标到第一行，按 yy 复制
#    然后按 p 粘贴一行

# 5. 删除某行：将光标移到该行，按 dd

# 6. 保存并退出：按 :x 回车
```

## 入门后值得记住的几条“神操作”

| 操作                    | 效果                           |
| ----------------------- | ------------------------------ |
| `ddp`                   | 交换当前行和下一行             |
| `dw` + `h` + `p`        | 移动单词位置                   |
| `.` （点号）            | 重复上一次修改操作（超级有用） |
| `Ctrl + o` / `Ctrl + i` | 在光标历史位置中后退/前进      |
| `%`                     | 在配对的括号 `()[]{}` 之间跳跃 |

## 学习建议

- **不要一次背太多**：先记住 `i` / `Esc` / `:wq` / `dd` / `yy` / `p` / `u` 就可以应付日常。
- **强迫自己用 Vim 一周**：每次修改文件都用 Vim，肌肉记忆会自然形成。
- **使用 `vimtutor`**：终端执行 `vimtutor`，是一个30分钟交互式教学工具，强烈推荐。
- **逐步增加新命令**：每周学2~3个新动作（如 `gg` / `G` / `%` / `.`）。

## 快速参考卡

```
启动     vim file
模式     Esc 回到正常模式  |  i 进入插入模式  |  : 命令模式
移动     h j k l   w b   0 $   gg G   :n
编辑     i a o   x dd yy p   u
保存     :w   :x   :wq   :q!
查找     /pattern   n N
替换     :%s/old/new/g
```

记住：**能退出去是第一要务**，能存下来是第二，然后慢慢积累。Vim 会成为你最高效的文本编辑伙伴。
