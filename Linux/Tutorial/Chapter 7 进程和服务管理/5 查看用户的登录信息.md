# 查看用户的登录信息

进程管理的主要目的之一就是查看并了解系统运行的状态信息，比如有哪些用户当前正在登录系统、系统资源的消耗和使用情况等。下面介绍如何查看用户登录信息。

Linux 是一个多用户的操作系统，在同一时间内可能会有多个用户同时登录使用系统，可以通过 users、who 或者 w 命令来查看当前有哪些用户正在登录系统。

## users 命令——查看登录用户名

users 命令功能比较简单，它只能列出当前登录的用户名。

```shell
[root@localhost ~]# users
root root
```

结果显示当前共有 2 个用户以 root 的身份在不同的终端上登录。

## who 命令——查看登录用户的信息

who 命令显示的信息就要详细一些，可以列出用户名、终端、登录时间和来源地点等信息。

例如，下面执行 who 命令后的显示结果共有 3 行，每行的含义如下：

- 第一行信息表示 root 用户在终端 tty1 上登录，由于 tty1 是一个虚拟终端，因此这表示 root 是在系统本地登录。
- 第二行信息表示 root 用户在终端 pts/0 上登录，由于 pts/0 是一个伪终端，因此这表示 root 用户是在远程登录，最后的 IP 地址就是用户所在的客户端 IP。
- 第三行信息同样表示 root 用户在远程终端 pts/2 上登录，客户端 IP 地址为 192.168.15.1。

```shell
[root@localhost ~]# who
root     tty1         2022-03-28 10:19 (tty1)
root     pts/0        2022-03-28 10:18 (192.168.15.1)
root     pts/1        2022-03-28 10:18 (192.168.15.1)
```

## w 命令——查看登录用户的详细信息

w 命令可视为增强版的 who 命令，它显示的信息更为详细。除 who 命令的功能之外，它还可以列出用户的登录时间和正在执行的命令等信息。

在 w 命令显示的第一行信息中，还依次显示了系统当前时间、系统已经启动的时间、当前登录到系统的用户个数，以及在过去 1min、5min、15min 内的 CPU 的平均负载情况。这部分信息与 top 命令所显示的第一行信息相同。

```shell
[root@localhost ~]# w
10:21:12 up 3 min,  3 users,  load average: 0.10, 0.08, 0.02
root     tty1      10:19    3:27   0.02s  0.02s -bash
USER     TTY        LOGIN@   IDLE   JCPU   PCPU WHAT
root     pts/0     10:18    0.00s  0.00s  0.00s -bash
root     pts/1     10:18    2:35   0.26s  0.26s w
```

## last 命令——查看登录记录

使用 last 命令可以看到系统的登录记录，即哪些人曾经以什么用户身份在什么终端上登录本机。

```shell
[root@localhost ~]# last
root   tty1         tty1             Mon Mar 28 10:19   still logged in
root     pts/1        192.168.15.1     Mon Mar 28 10:18   still logged in
root     pts/0        192.168.15.1     Mon Mar 28 10:18   still logged in
reboot   system boot  5.14.0-71.el9.x8 Mon Mar 28 10:17   still running
root     pts/1        192.168.15.1     Sun Mar 27 22:38 - 22:50  (00:12)
……
```

由于 last 命令是通过查询日志文件来获取的登录信息，而日志文件又很容易被黑客篡改，因此不能单纯以该命令的输出信息来判断系统有无被恶意入侵。

## “踢出”可疑用户

下面以用户“test”为例演示如何将可疑用户“踢出”系统。

首先以普通用户“test”的身份在 XShell 上远程登录 Linux 系统，然后在虚拟机中执行 who 命令或 w 命令找到登录到系统中的可疑用户（jerry），并记录其登录终端的编号（pts/0）：

```shell
[root@localhost ~]# who
root     pts/0        2022-03-28 10:18 (192.168.15.1)
root     pts/1        2022-03-28 10:18 (192.168.15.1)
root     tty1           2022-03-28 10:19 (tty2)
test     pts/2        2022-03-28 11:17 (192.168.15.1)
test     pts/3        2022-03-28 11:17 (192.168.15.1)
```

查找可疑用户登录终端所对应的进程 PID（10763）：

```shell
[root@localhost ~]# ps aux | grep pts/2 | grep -v grep
test      140224  0.6  0.2  19680  7696 ?        S    11:17   0:00 sshd: test@pts/2,pts/3
test      140239  0.0  0.1 224224  5716 pts/2    Ss+  11:17   0:00 -bash
```

强制结束该进程，“踢出”对应的用户：

```shell
[root@localhost ~]# kill -9 140239
[root@localhost ~]# who
root     pts/0        2022-03-28 10:18 (192.168.15.1)
root     pts/1        2022-03-28 10:18 (192.168.15.1)
spider   tty2         2022-03-28 10:19 (tty2)
```
