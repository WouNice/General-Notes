# 常用操作

## 修改hosts主机映射文件

hosts 又称 host table，可译为“主机表”，以表的形式存储了主机名和IP地址的映射关系。

1、操作 hosts 文件需要 root 权限，所以我们需要先切换到 root 用户。

```shell
su -
```

2、vim 编辑`/etc/hosts`文件

```shell
vim /etc/hosts
```

3、输入你想要更改的内容，然后按`:wq`保存退出即可。

```shell
127.0.0.1 test.com
```

## 删除历史操作

1、清除当前shell的历史记录：

```shell
history -c
```

history -c 只是清除当前shell的历史记录，因为系统一般会把信息保存在`.bash_history`中，只要文件中内容没有改变，那么信息也不会变。

> 如果是在shell脚本中调用history -c清空当前shell的历史命令，是不会成功的，因为bash执行命令时默认是会产生一个子进程来执行该命令，在子进程中执行history -c不是清除你当前shell的历史命令了。可以使用source来执行脚本（`source ./xxx.sh`），source 指在当前bash环境下执行命令

2、清空`.bash_history`文件的历史记录：

```shell
echo > /root/.bash_history
```

3、部分删除操作：

通过vim修改`~/.bash_history`文件内容：

```shell
vim ~/.bash_history
```

读取`~/.bash_history`文件并将其内容添加到缓存中：

```shell
history -r
```

## 清空终端的内容

两种方法，在终端输入clear或者reset命令：

- clear 命令：这个命令并非真正清空，只是把内容全部向上滚，让它们消失在视野中。

- reset 命令：这个命令是真正的清空。
