# 存出和载入镜像

## 存出镜像

如果要导出镜像到本地文件，可以使用`docker [image] save`命令。

该命令支持-o、-output string参数，导出镜像到指定的文件中。

例如，导出本地的`ubuntu:latest`镜像为文件`ubuntu_latest.tar`：

```
$ docker save -o ubuntu_latest.tar ubuntu:latest
```

## 载入镜像

可以使用`docker [image] load`将导出的`.tar`文件再导入到本地镜像库。

支持-i、-input string选项，从指定文件中读入镜像内容。

例如，从文件ubuntu_latest.tar导入镜像到本地镜像列表：

```
$ docker load -i ubuntu_latest.tar
```

或者：

```
$ docker load < ubuntu_latest.tar
```

这将导入镜像及其相关的元数据信息（包括标签等）。
